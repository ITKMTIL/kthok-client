# K-Thok — ภาพรวมผลิตภัณฑ์

"KMITL Thok" (thok = คุย) แชตนิรนาม 1 ต่อ 1 สำหรับนักศึกษา สจล. อารมณ์แบบ Tinder แต่ไม่ต้อง match กัน: กด "หาเพื่อนคุย" แล้วถูกจับคู่ทันที (เข้าห้องที่มีคนรอ หรือเปิดห้องรอ)

แรงบันดาลใจ: https://drinksonme.live/ (สไตล์ลายเส้นวาดมือ) — ให้เครดิตใน README และ footer หน้าเว็บ

## ฟีเจอร์ (สถานะ 2026-10-03)

- เลือกหัวข้อห้อง (คุยทั่วไป/ติวสอบ/เกม/อยากระบาย/หาเพื่อนกินข้าว) จับคู่เฉพาะหัวข้อเดียวกัน, ป้าย "มีคนรอ" บนคณะ/หัวข้อ, ไม่จับคู่ซ้ำคนเดิมทันที, คนโดนบล็อก/รายงานบ่อยรอนานขึ้น
- คำถามชวนคุย (ปุ่มหลอดไฟ), มินิเกม XO + เป่ายิ้งฉุบ (เมนู ⋮)
- หลังจบห้อง (ทั้งคนออกและคนถูกทิ้ง เห็นหน้าจบห้อง): ให้คะแนน, "อยากคุยต่อ" แลก contact เมื่อกดทั้งคู่, ลิงก์รายงาน; "คนถัดไป" ข้ามไปหาห้องใหม่ทันที
- รายงาน: เลือกเหตุผล + แนบข้อความ (≤20) + โน้ต, admin ตรวจในคิวที่ `/admin` แล้วระงับ 1/7/30 วัน/ถาวร, ยกฟ้อง, ปลดระงับ
- แจ้งเตือนตอนปิดจอ (PWA service worker `public/sw.js` + Web Push) เปิดเองใน lobby, iPhone ต้อง Add to Home Screen
- Dark mode: ตามเครื่อง/สว่าง/มืด (ปุ่มใน header)
- จับคู่ทันที + เลือกคณะที่อยากคุย (รอ `PREFERENCE_GRACE_MS` 8s แล้ว fallback ไปห้องว่างอื่น) + แบนเนอร์ชัด ๆ เมื่อไม่ได้คณะที่ขอ
- ล็อกอิน Google เฉพาะ `@kmitl.ac.th` คณะดึงจากรหัส ไม่มี client id = โหมดทดลองเลือกคณะเอง
- นามแฝงตั้งเอง/สุ่ม และโชว์ชื่อตัวเองบน header
- แชต: typing, รีแอคชัน 6 ตัว, กรองคำหยาบ (mask), rate limit
- ข้อความเสียง: อัดสูงสุด 60s, ฟังซ้ำ/seek/1x 1.5x 2x, เล่นทีละอัน, ลดเสียงเพลงระหว่างอัด/ฟัง, ซ่อนไมค์ระหว่างโทร
- ฟังเพลง YouTube ด้วยกัน: คิว, play/pause/skip, server เป็นเจ้าของ state
- โทรเสียง WebRTC (ต้องคุยครบ `CALL_MIN_MESSAGES` ก่อน, อีกฝ่ายต้องกดรับ), TURN Cloudflare, ปิดได้ด้วย env
- แชร์ข้อความเป็นรูป PNG (สร้างใน browser, ซ่อนชื่ออีกฝ่ายเป็นค่าเริ่มต้น)
- เสียงแจ้งเตือน (Web Audio) + ตัวนับบน title, ปิดเสียงได้
- หลุดแล้วกลับห้องเดิมได้ภายใน `RECONNECT_GRACE_MS` 120s (พับจอ)
- มือถือ: แผงเพลงหุบได้, `--app-height` ตาม visualViewport กันแป้นพิมพ์บัง
- บล็อกคู่สนทนา, ให้คะแนนห้อง (ขึ้น/ลง)
- admin dashboard `/admin` (ยอดรวม, ไม่มีข้อมูลรายคน), admin จับคู่ตัวเองได้
- Splash GSAP ธีมรถไฟ (ครั้งเดียวต่อแท็บ), mascot 2 ตัว (ตัวเดิม + ตัวผิวแทนผม oppa ไม่มีจุก), ต้นไม้, รถไฟ สจล.

## ความชอบของผู้ใช้ (เจ้าของโปรเจกต์)

- UI ไม่มี emoji ยกเว้นรีแอคชัน ใช้ lucide icon
- ภาษาไทยในหน้าเว็บ น้ำเสียงเป็นกันเอง
- ข้อความเรื่องความเป็นส่วนตัวต้องเด่น ชัด
- ปุ่ม Google เต็มความกว้าง
- อนิเมชันน่ารักแต่ไม่รก, เคารพ `prefers-reduced-motion`
- ชอบให้ plan ก่อนลงมือในงานใหญ่ แล้วสั่ง "เริ่มเลย"
